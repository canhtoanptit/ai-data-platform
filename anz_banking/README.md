# anz_banking (dbt project)

This is the dbt project for the ANZ Collections Platform learning repo.

Run everything from the **repo root** using the `Makefile` there
(`make debug`, `make fresh`, `make build`, `make docs`).

See the root [`README.md`](../README.md) for setup and
[`LEARNING.md`](../LEARNING.md) for the step-by-step learning path.
